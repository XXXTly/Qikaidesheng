# 骑开得胜 - 高保真网页原型

## 项目概述

本产品是为大学生创业计划竞赛（"小挑"）设计的高保真可交互网页原型，面向外卖骑手的算法规则解读与申诉辅助工具。

- **项目名称**：骑开得胜
- **品牌口号**：让骑手看得懂规则、写得了申诉、留得下证据
- **目标用户**：外卖骑手及为骑手提供权益服务的公共服务机构
- **设计目的**：用于院级创业竞赛选拔和现场产品演示

## 原型特点

1. **移动端优先**：参考 390×844 像素手机画布设计
2. **完整业务流程**：覆盖「选问题 → 填情况 → 看规则 → 备证据 → 出初稿」全流程
3. **真实可点击**：所有按钮和入口均可交互，支持页面跳转、弹窗、搜索、筛选
4. **无需后端**：所有数据为预设演示数据，直接在浏览器中运行
5. **统一视觉**：深绿色主色 + 白色/浅灰背景 + 橙色辅助色，公共服务产品风格

## 页面清单

| 页面 | 说明 |
|------|------|
| 首页 | 品牌展示、三大主入口、常见场景、使用流程 |
| 问题选择 | 四类申诉场景选择 |
| 情况填写 | 平台、时间、事件经过、已采取措施表单 |
| 规则解读 | 规则原文、大白话解释、适用条件、信息来源 |
| 证据清单 | 可勾选的证据材料清单 |
| 申诉初稿 | 按事实、证据、规则、诉求四区块生成的申诉文本 |
| 规则库/案例库 | 规则分类筛选、案例搜索、详情弹窗 |
| 我的 | 草稿、历史、使用说明、反馈、隐私说明 |

## 如何查看

### 方式一：直接打开

双击 `index.html` 文件，使用浏览器（Chrome / Edge / Safari）打开即可。

### 方式二：本地服务器（推荐用于手机预览）

在项目目录下运行：

```bash
npx serve .
```

然后在浏览器中访问显示的本地地址。同一局域网内手机也可访问。

### 方式三：VS Code Live Server

在 VS Code 中安装 Live Server 插件，右键 `index.html` → "Open with Live Server"。

## 演示建议

1. 从首页点击「我要申诉」进入问题选择
2. 选择「商家出餐延误」或其他场景
3. 查看自动填充的示例信息，点击「查看对应规则」
4. 阅读规则解读后点击「检查证据」
5. 勾选证据材料后点击「生成申诉初稿」
6. 在申诉初稿页可复制或编辑文本
7. 通过底部导航切换「规则/案例」和「我的」页面

## 技术说明

- 纯 HTML + CSS + JavaScript，无框架依赖
- 单页应用（SPA）架构，页面切换通过 JavaScript 控制
- 所有数据为本地静态数据，不调用任何外部接口
- 适配桌面端浏览器窗口：超过 430px 宽度时显示手机外框

## 设计原则

- **真实性**：所有演示数据均为模拟案例，不伪装真实骑手记录
- **合规性**：不编造平台内部算法参数、申诉成功率等未经证实的数据
- **可用性**：流程清晰，按钮明确，适合在答辩现场快速演示
- **扩展性**：后续可在此基础上接入真实后端、数据库和 AI 能力
